# Absolute-Flight-Simulator-
Absolute Flight Simulator
Absolute Flight is a flight simulator built with Three.js.

Current Features:

Boeing 787-8
Custom aerodynamic model <br>
Wheel-contact landing system <br>
Real-time atmosphere and lighting<br>
Ground handling and takeoff physics<br>
Planned Features:

Global terrain<br>
Advanced landing gear physics<br>
Cockpit instruments<br>
Flight controls and hardware support<br>
Additional aircraft<br>
Development Status
Active development.
